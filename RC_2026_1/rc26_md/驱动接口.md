# 第一部分：模块接口速查

## 1. 串口驱动 (SerialDriver)

> 双串口架构：Odom 串口负责位姿/里程计，Command 串口负责指令/反馈。

### 配置参数

```yaml
rc26_decision:
  ros__parameters:
    enable_cmd_serial: true
    cmd_serial_port: "/dev/ttyUSB1"
    enable_odom_serial: true
    odom_serial_port: "/dev/ttyUSB0"
    enable_heartbeat: true
    heartbeat_rate_hz: 1
```

### 黑板键值

| 键名 | 类型 | 说明 |
|:-----|:-----|:-----|
| `cmd_serial` | `shared_ptr<SerialDriver>` | 指令串口句柄 |
| `cmd_serial_reconnecting` | `bool` | 串口是否正在重连 |
| `grab_tip_done` | `bool` | 抓取矛头完成 (反馈自动映射) |

### C++ 接口

```cpp
// 发送指令
auto serial = config().blackboard->get<std::shared_ptr<SerialDriver>>("cmd_serial");
serial->sendCommand(CommandID::GRAB_TIP);

// 检查反馈
bool done = config().blackboard->get<bool>("grab_tip_done");
```

## 2. 智能导航 (SmartWaypointNavigator)

> 支持语义航点、参数热切换、安全模式联动、MCU 指令下发。

### 配置参数 (waypoints.yaml)

```yaml
static_points:
  merlin_entry_1:
    pose: {x: 1.5, y: 2.0, yaw: 1.57}
    speed_profile: "FAST"
    nav_safety_mode: "MF_SAFE"
    mcu:
      nav_mode: "NORMAL"
      speed_mps: 1.2
    tolerance: {xy: 0.15, yaw: 0.1}
```

### 黑板键值

| 键名 | 类型 | 说明 |
|:-----|:-----|:-----|
| `waypoint_manager` | `shared_ptr<WaypointManager>` | 航点管理器 |
| `smart_waypoint_navigator` | `shared_ptr<SmartWaypointNavigator>` | 智能导航器 |

### 行为树节点

| 节点名 | 端口 | 说明 |
|:-------|:-----|:-----|
| `NavToSmartPoint` | `target_name` | 导航到语义航点 |

### 添加新底盘模式

修改 4 个文件：
1. `protocol.hpp` - 添加 `CommandID`
2. `smart_waypoint_types.hpp` - 添加 `McuNavMode` 枚举
3. `waypoint_manager.cpp` - 添加字符串解析
4. `smart_waypoint_navigator.cpp` - 添加指令映射

## 3. 台阶层级 (base_ground)

> 计算机器人当前台阶层级，供行为树判断上/下台阶完成。

### ROS 话题

| 话题 | 类型 | 说明 |
|:-----|:-----|:-----|
| `base_ground/level` | `Int32` | 当前绝对层级 (0, 1, 2...) |
| `base_ground/stair_delta` | `Int8` | 层级变化脉冲 (+1/-1) |
| `base_ground/stable` | `Bool` | 是否稳定 |

### 黑板键值

| 键名 | 类型 | 说明 |
|:-----|:-----|:-----|
| `current_level` | `int32` | 当前层级 |
| `stair_delta` | `int8` | 层级变化脉冲 |
| `base_ground_stable` | `bool` | 是否稳定 |
| `stair_climb_done` | `bool` | 上台阶完成 |
| `stair_descend_done` | `bool` | 下台阶完成 |

### 行为树节点

| 节点名 | 说明 |
|:-------|:-----|
| `StairClimb` | 等待上台阶完成 (level >= start + 3) |
| `StairDescend` | 等待下台阶完成 (level <= start - 3) |

## 4. 视觉推理 (rc26_vision)

> 基于 YOLO 的目标检测，支持多模型切换。

### 配置参数

**单模型模式**：
```yaml
rc26_decision:
  ros__parameters:
    enable_vision: true
    vision_model_path: "/path/to/yolo.onnx"
    vision_conf_thresh: 0.5
```

**多模型模式** (vision_models.yaml)：
```yaml
vision:
  default_model: "yolo_default"
  models:
    yolo_default:
      engine: onnxruntime
      model_path: "/path/to/yolo.onnx"
      conf_thresh: 0.5
      labels: ["R_R1", "B_R1", "T_03"]
    yolo_small:
      engine: onnxruntime
      model_path: "/path/to/yolo_small.onnx"
      conf_thresh: 0.6
      input_w: 320
      input_h: 320
```

### 黑板键值

| 键名 | 类型 | 说明 |
|:-----|:-----|:-----|
| `vision_manager` | `shared_ptr<VisionInferenceManager>` | Manager 句柄 |
| `vision_running` | `bool` | 推理是否运行中 |
| `vision_ok` | `bool` | 系统健康状态 |
| `vision_has_target` | `bool` | 是否检测到目标 |
| `vision_attr_kind` | `int` | 目标属性 (3=Truth, 4=False) |
| `vision_distance_m` | `double` | 目标距离 (米) |
| `vision_current_model` | `string` | 当前模型 ID |

### 行为树节点

| 节点名 | 端口 | 说明 |
|:-------|:-----|:-----|
| `VisionStart` | `model_id` (可选) | 启动推理 |
| `VisionStop` | 无 | 停止推理 |
| `VisionSetModel` | `model_id` | 切换模型 |
| `WaitVisionTarget` | `target_attr`, `max_dist`, `timeout` | 等待目标 |

**WaitVisionTarget 端口**：
- `target_attr`: `Truth` / `False` / 空 (任意)
- `max_dist`: 最大距离 (米)，<=0 不限制
- `timeout`: 超时 (ms)，默认 1000

### C++ 接口

```cpp
auto manager = config().blackboard->get<
    std::shared_ptr<rc26_vision::VisionInferenceManager>>("vision_manager");

manager->switchModel("yolo_small");  // 切换模型
manager->start();                     // 启动推理
manager->stop();                      // 停止推理
```

# 第二部分：行为树示例

## 基础示例

### 示例 1：发送指令并等待反馈

```xml
<Sequence>
    <GrabTip/>  <!-- 发送抓取指令，等待 grab_tip_done -->
</Sequence>
```

```cpp
// GrabTip 实现
BT::NodeStatus GrabTipAction::onStart() {
    auto serial = config().blackboard->get<std::shared_ptr<SerialDriver>>("cmd_serial");
    serial->sendCommand(CommandID::GRAB_TIP);
    return BT::NodeStatus::RUNNING;
}

BT::NodeStatus GrabTipAction::onRunning() {
    if (config().blackboard->get<bool>("grab_tip_done")) {
        return BT::NodeStatus::SUCCESS;
    }
    return BT::NodeStatus::RUNNING;
}
```


## C++ 自定义节点模板

```cpp
#include "rc26_serial/serial_driver.hpp"
#include "rc26_serial/protocol.hpp"

class MyAction : public BT::StatefulActionNode {
public:
    BT::NodeStatus onStart() override {
        // 发送指令
        auto serial = config().blackboard->get<
            std::shared_ptr<SerialDriver>>("cmd_serial");
        serial->sendCommand(CommandID::MY_COMMAND);
        return BT::NodeStatus::RUNNING;
    }

    BT::NodeStatus onRunning() override {
        // 检查串口重连
        if (config().blackboard->get<bool>("cmd_serial_reconnecting")) {
            return BT::NodeStatus::RUNNING;
        }

        // 检查视觉结果
        bool has_target = false;
        double distance_m = 0.0;
        int attr_kind = 0;
        config().blackboard->get("vision_has_target", has_target);
        config().blackboard->get("vision_distance_m", distance_m);
        config().blackboard->get("vision_attr_kind", attr_kind);

        if (has_target && attr_kind == 3 && distance_m < 1.5) {
            return BT::NodeStatus::SUCCESS;
        }

        // 检查台阶层级
        int32_t level = 0;
        config().blackboard->get("current_level", level);

        return BT::NodeStatus::RUNNING;
    }

    void onHalted() override {}
};
```
