# rc26_base_ground

## 模块简介

`rc26_base_ground` 是已归档的 R2 基础标高与离散层级估计源码包。当前主运行时不再编译、启动或消费它；默认 CMake 只完成包配置，不生成节点、库、测试或安装目标。

历史实现曾整合 Point-LIO 高频里程计，通过滑动窗口滤波与状态机，为下游规划、决策及机构动作提供 2D 导航基准平面、离散地形层级和稳定性信号。这条链路现在已从默认运行时中移除。

## 归档历史功能

1. 离散地形层级估计：将连续的 Z 轴高度变化量化为离散的台阶层级，并过滤掉坡面行驶和颠簸带来的瞬态噪声，确保层级跳变的准确性。
2. 双重稳定性语义判别：根据底层运动状态拆分出地形稳定性与操作稳定性。地形稳定性用于地形门控与层级更新，操作稳定性则叠加了严格的速度约束，专门为机械臂等精密操作提供安全触发信号。
3. 动态基准面校准：利用多样本窗口均值对初始零层基准面进行鲁棒标定，有效避免启动阶段由于底盘微小晃动导致的基准面偏移，并支持调试阶段的手动参数覆盖。
4. 异常姿态与搬运保护：专门针对比赛中 R1 搬运 R2 的场景设计了被举起保护逻辑。当检测到高度发生远超单级台阶的跃变时，自动冻结层级更新与稳定性信号，防止系统误判为自主爬升。同时引入了绝对角度与垂向速度门控，防止机器人在长缓坡上的连续高度漂移引发误触发。

## 归档历史接口

该模块历史上订阅来自三维激光雷达里程计的高频位姿及速度信息作为唯一高度与姿态数据源，并发布以下状态：

- 地形层级：当前机器人所处的离散台阶层级数字，供决策和局部规划器使用。
- 层级变化事件：仅在发生上下台阶瞬间触发的增量信号，常被行为树订阅。
- 地形稳定状态：指示底盘是否处于平稳的地形环境中。
- 操作稳定状态：指示底盘是否完全静止，适合机械臂等附加机构动作。
- 被举起状态：安全保护信号，提示机器人正处于被外部力量搬运的过程中。
- 连续地面高度诊断：未经离散化处理的滤波后地面高度值，用于调试或限速策略的连续输入。

此外，模块维护并广播一个带有当前层级高度的 2D 导航基准平面坐标系，使下游 2D 导航栈无需处理复杂的 3D 姿态变换即可在各个台阶上稳定运行。

## 当前边界

- 不参与 `rc26_bringup`、`rc26_decision`、Nav2、smoke CI 的默认运行时链路。
- 默认不发布 `base_ground/*` 话题，也不广播 `base_ground` TF。
- 当前主链没有任何模块订阅 `base_ground/*` 数据；`rc26_decision` 只保留楼梯相关黑板默认值，不再从本包更新这些键。
- 如未来恢复，必须先重新定义接口契约、启动入口、验证范围和文档边界。

关于具体的命令行调试方法与参数调节指南，请参阅仓库根目录的 `调试/rc26_base_ground调试.md`。
