## 1. 一键验收脚本

脚本路径：
- `src/rc26_localization/scripts/run_localization_acceptance.sh`

功能：
- 单包编译（`colcon build --parallel-workers 1 --packages-select rc26_localization`）
- 启动 `rc26_bringup/localization.launch.py`
- 可选回放 rosbag
- 自动采集 `PERF_METRIC`/`RELOC_METRIC`、`pose_with_cov`/`diagnostics` 观测信息
- 输出验收摘要与原始日志

### 1.1 推荐用法（bag 回放）

```bash
cd /home/potato/RC_2026
./src/rc26_localization/scripts/run_localization_acceptance.sh \
  --map /绝对路径/prior.pcd \
  --bag /绝对路径/test.mcap \
  --duration 240
```

### 1.2 实机在线采样（无 bag）

```bash
cd /home/potato/RC_2026
./src/rc26_localization/scripts/run_localization_acceptance.sh \
  --map /绝对路径/prior.pcd \
  --duration 120
```

### 1.3 关键参数

- `--map`：必填，先验点云绝对路径
- `--bag`：可选，提供则自动 `use_sim_time=true`
- `--duration`：采样秒数（默认 120）
- `--skip-build`：跳过编译（迭代调参时常用）
- `--output-dir`：自定义输出目录（默认 `/tmp/localization_acceptance_时间戳`）

## 2. 验收输出解读

脚本输出目录结构：
- `acceptance_summary.md`：验收摘要（首看）
- `raw/build.log`：编译日志
- `raw/localization.launch.log`：节点运行日志
- `raw/metrics.log`：过滤后的 `PERF_METRIC`/`RELOC_METRIC`
- `raw/pose_cov_info.log` / `raw/diagnostics_info.log`：topic 存在性与类型
- `raw/pose_cov_hz.log` / `raw/diagnostics_hz.log`：频率采样

对应执行方案验收口径：
- 退化环境可用性：看 `GLOBAL_RECOVERY` 日志条数趋势（建议与改造前同 bag 对比）
- 重定位成功率：看 `RELOC_METRIC accepted=1` 次数与接受率
- TF 连续性：看 `localization.launch.log` 是否有明显中断/异常告警，并结合频率日志判断
- 可观测性：`pose_with_cov` 与 `diagnostics` topic 存在且持续发布
- 观测质量：`diagnostics` 中应出现 `h_min_eig/h_max_eig/h_cond/sigma_xy/sigma_yaw/obs_cov_source/hard_degen_consec`

## 4. 典型问题与排查

- 现象：频繁进入 `GLOBAL_RECOVERY`
  - 先看：`metrics.log` 中 `PERF_METRIC phase=LOCAL` 与 `degen_risk` 相关日志
  - 再看：`localization.yaml` 的 `degen_enable`、`degen_eigenvalue_ratio_threshold`

- 现象：L0 很少胜出或完全不走
  - 先看：是否存在 S1 spike（`imu_spike_recent` 触发依赖 IMU spike）
  - 再看：`l0_enable`、`l0_max_imu_gap_ms` 与 IMU 话题时序

- 现象：`/localization/pose_with_cov` 无数据
  - 先看：节点是否启动成功、地图是否加载成功
  - 再看：`registered_scan` 是否持续输入
  - 再看：是否误用 `ros2 run ... --params-file localization.yaml`（空数组参数可能触发参数解析异常），建议优先 `ros2 launch rc26_bringup localization.launch.py`

- 现象：UWB 开启后 L1 候选异常
  - 先看：`uwb_topic` 是否有新鲜数据（`uwb_max_stale_sec`）
  - 再看：UWB 坐标是否已标定到 `map` 系

## 5. 常用热更新参数（在线调参）

示例（节点名默认 `/localization`）：

```bash
ros2 param set /localization degen_eigenvalue_ratio_threshold 0.02
ros2 param set /localization sc_topk 8
ros2 param set /localization dynamic_filter_enable true
ros2 param set /localization parallel_reloc_enable true
```

建议：
- 每次只改 1~2 个参数
- 使用同一 bag 重复回放做 A/B 对比
- 对比 `acceptance_summary.md` 中同口径指标，避免主观判断
