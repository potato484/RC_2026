快捷键说明

工具切换

以下快捷键适用于大多数模式；如果当前工具独占全部按键，则以该工具自身行为为准。
C 切换到聚焦视角工具。
M 切换到移动视角工具。
N 切换到测距工具。
U 切换到发布点位工具。
S 切换到选择工具。
G 切换到二维目标位姿工具。
P 切换到二维初始位姿工具。

视角控制

以下快捷键仅在使用移动视角或交互工具时有效。
F 将焦点移动到鼠标下方的三维点。部分对象或部分设备上可能不可用。
Z 回到默认视角位置并重新观察原点。

以下快捷键仅在使用选择工具时有效。
F 将焦点移动到当前选中对象的中心位置。

显示列表操作

Ctrl-N 添加显示项。
Ctrl-X 移除显示项。
Ctrl-R 重命名显示项。

文件操作

Ctrl-O 打开配置文件。
Ctrl-S 保存配置文件，必要时会弹出文件选择窗口。
Ctrl-Q 退出可视化台，并在退出前保存当前配置。

鼠标操作

环绕视角

在该视角下，镜头始终围绕一个焦点观察。你既可以绕着焦点旋转，也可以直接移动焦点本身。
左键 拖动可绕焦点旋转。
中键
或
Shift + 左键
 拖动可平移焦点。
滚轮 向上或向下滚动可缩放视角。
右键 上下拖动可缩放视角。
Shift + 右键 上下拖动可沿前后方向移动焦点。

平面环绕视角

与环绕视角类似，但焦点会被约束在 Z=0 的地面平面上。
左键 拖动可绕焦点旋转。
中键
或
Shift + 左键
 拖动可在地面平面内平移焦点。
滚轮 向上或向下滚动可缩放视角。
右键 上下拖动可缩放视角。

第一人称视角

类似第一人称游戏中的观察方式，拖动鼠标即可改变观察方向。
左键 拖动可旋转观察方向。
中键
或
Shift + 左键
 拖动可左右、上下平移视角。
滚轮 向上或向下滚动可前后移动视角。
右键 上下拖动可前后移动视角。

俯视正交视角

从上往下观察场景的正交视角。
左键 左右拖动可旋转视角。
中键
或
Shift + 左键
 拖动可在 XY 平面内平移视角。
滚轮 向上或向下滚动可缩放视图。
右键 上下拖动可缩放视图。
