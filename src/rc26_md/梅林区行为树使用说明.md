# 梅林区行为树使用说明

## 1. 概述

梅林区 (MF Area) 行为树实现了 R2 机器人在梅林区域的自主决策系统，包括：
- 进入梅林区
- 识别和拾取 R2 KFS
- 路径规划和移动
- 安全退出梅林区

## 2. 文件结构

```
rc26_decision/
├── include/rc26_decision/mf/
│   └── mf_area.hpp          # 节点声明 + 数据结构
├── src/mf/
│   └── mf_area.cpp          # 节点实现
├── behavior_trees/
│   └── mf_tree.xml          # 行为树 XML
└── config/waypoints/
    └── waypoints_red.yaml   # 导航点配置
```

## 3. 核心数据结构

### 3.1 KFSType 枚举
```cpp
enum class KFSType : uint8_t {
    NONE = 0,     // 无 KFS
    R1 = 1,       // R1 KFS (Logo图案) - 禁止触碰
    R2 = 2,       // R2 KFS (甲骨文图案) - 目标
    FAKE = 3,     // 假 KFS (小篆图案) - 禁止触碰
    UNKNOWN = 4   // 未知
};
```

### 3.2 MerlinMapManager
管理梅林区 3x4 格子地图状态：
- `getDepth(grid_id)`: 获取格子高度层级 (1-3)
- `getKFS(grid_id)`: 获取格子 KFS 状态
- `setKFS(grid_id, type)`: 更新格子 KFS 状态
- `canTraverse(from, to)`: 判断两格子间是否可跨越
- `isWalkable(from, to)`: 判断目标格子是否可走

## 4. 行为树节点说明

### 4.1 动作节点 (Action Nodes)

| 节点名 | 功能 | 输入端口 | 输出端口 |
|:-------|:-----|:---------|:---------|
| `SetNavMode` | 切换导航模式 | `mode` | - |
| `ScanSurroundings` | 扫描周围环境 | - | - |
| `SelectNextGrid` | 决策下一步 | - | `next_action`, `target_grid` |
| `NavToMerlinGrid` | 导航到梅林格子 | `grid_id` | - |
| `GrabKFS` | 夹取 KFS | `grid_id` | - |
| `IncrementKFSCount` | KFS 计数+1 | - | - |
| `UpdateMapKFS` | 更新地图状态 | `grid_id`, `kfs_type` | - |
| `StairClimb` | 上台阶 | - | - |
| `StairDescend` | 下台阶 | - | - |

### 4.2 条件节点 (Condition Nodes)

| 节点名 | 功能 | 输入端口 |
|:-------|:-----|:---------|
| `CheckExitCondition` | 检查退出条件 | - |
| `CheckR1Blocking` | 检查 R1 阻挡 | - |
| `CheckKFS` | 检查格子 KFS 状态 | `grid_id`, `expected_state` |
| `CheckLoad` | 检查装载数量 | `min_load`, `max_load` |

## 5. 导航模式说明

| 模式 | 用途 | 说明 |
|:-----|:-----|:-----|
| `MF_SAFE` | 安全模式 | Drop层开启，边缘视为障碍 |
| `MF_TRAVERSE` | 跨越模式 | Drop层关闭，用于跨越方块 |
| `MF_EXIT` | 出口模式 | Drop层关闭，用于下台阶离开 |
| `NORMAL` | 普通模式 | 梅林区外使用 |

**切换顺序**: 必须先切模式，再发动作指令；动作完成后立即切回 `MF_SAFE`。

## 6. 黑板变量 (Blackboard)

| 变量名 | 类型 | 默认值 | 说明 |
|:-------|:-----|:-------|:-----|
| `team` | string | "blue" | **自动设置** 由 decision_node 从 ROS 参数读取 |
| `target_kfs_count` | int | 2 | 目标 KFS 数量 |
| `exit_grid` | int | 10 | 出口格子编号 |
| `kfs_on_board` | int | 0 | 当前装载 KFS 数量 |
| `current_grid` | int | 2 | 当前所在格子 |
| `merlin_map` | shared_ptr | - | 地图管理器 (自动创建) |
| `next_action` | string | - | 下一步动作 (GRAB/MOVE/WAIT) |
| `target_grid` | int | - | 目标格子编号 |

## 7. 导航点配置 (waypoints_red.yaml)

### 7.1 配置文件位置
```
rc26_decision/config/waypoints/waypoints_red.yaml
```

### 7.2 必须配置的导航点

| 导航点名 | 用途 | 配置要点 |
|:---------|:-----|:---------|
| `mf_entry` | 梅林入口 | 2号格前方100mm |
| `mf_entry_back` | 后退等待点 | 入口后方1500mm |
| `mf_exit` | 梅林出口 | 10号格前方1000mm |
| `mf_grid_1` ~ `mf_grid_12` | 12个格子中心 | 实测坐标 |

### 7.3 坐标测量方法

1. 在实际场地上标记格子中心点
2. 使用 SLAM 建图后，在 RViz 中读取坐标
3. 填入 `waypoints_red.yaml` 对应字段

### 7.4 格子高度配置 (depth)

**红方:**
| 格子 | 高度(mm) | depth值 |
|:-----|:---------|:--------|
| 1, 3, 7, 9, 11 | 400 | 2 |
| 2, 6, 10, 12 | 200 | 1 |
| 4, 8 | 600 | 3 |
| 5 | 400 | 2 |

**蓝方 (与红方对称):**
| 格子 | 高度(mm) | depth值 |
|:-----|:---------|:--------|
| 1, 3, 7, 9, 11 | 400 | 2 |
| 2, 4, 10, 12 | 200 | 1 |
| 6, 8 | 600 | 3 |
| 5 | 400 | 2 |

## 8. 行为树执行流程

```
MF_Main
├── 初始化黑板变量
├── MF_Entry (进门)
│   ├── 切换 MF_SAFE 模式
│   ├── 导航到入口
│   ├── 扫描检测 R1
│   │   └── 若有 R1 → 后退等待 5 秒
│   ├── 切换 MF_TRAVERSE 模式
│   ├── 进入 2 号格
│   └── 切回 MF_SAFE 模式
├── MF_Loop (核心循环)
│   ├── 检查退出条件
│   ├── 扫描更新地图
│   ├── 决策选择 (贪婪抓取 > 赶路 > 等待)
│   └── 执行动作
└── MF_Exit (出门)
    ├── 切换 MF_EXIT 模式
    ├── 导航到出口
    ├── 下台阶
    └── 切回 NORMAL 模式
```

## 10. 注意事项

1. **禁止 colcon build**: 本项目在 Windows 下开发，无法编译
2. **高度矩阵已固定**: 红方/蓝方地图高度已写入代码，勿修改
3. **模式切换顺序**: 必须先切模式再执行动作
4. **安全降级**: 未识别物体默认为假 KFS
5. **team 参数**: 通过 ROS 参数 `team` 设置队伍 ("red"/"blue")，自动写入黑板

## 11. 使用示例

### 11.1 启动时设置队伍
```bash
# 红方启动
ros2 run rc26_decision decision_node --ros-args -p team:=red

# 蓝方启动
ros2 run rc26_decision decision_node --ros-args -p team:=blue
```

### 11.2 NavToMerlinGrid 节点
该节点根据 `grid_id` 自动构建导航点名称 `mf_grid_X`：
```xml
<NavToMerlinGrid grid_id="{target_grid}"/>
<!-- 等效于导航到 mf_grid_1 ~ mf_grid_12 -->
```
