# rc26_omni_controller 录制与调参操作手册（R2）

## 适用范围

- 适用机器人：仅 `R2`（自动机器人）。

## 1. 怎么录制 rosbag

### 1.1 路线与轮次建议

- 路线 A：直线加减速 + 轻微转向（至少 3 次）
- 路线 B：标准圆弧 + S 弯（至少 3 次）
- 路线 C：动态障碍场景（至少 3 次）

### 1.2 录制 topic（必录 + 建议）

- 必录：`/odometry`、`/tf`、`/tf_static`、`/cmd_vel`、`/compute_time_ms`、`/collision_check_outside_map_count`
- 建议：`/collision_check_ms`、`/collision_d_min`、`/v_safe`、`/DM_IMU`
- 若要确保 `compute_time_ms` / `collision_check_ms` / `collision_d_min` / `v_safe` 有数据，先开启 `FollowPath.publish_debug=true`

### 1.3 录制命令模板

```bash
cd /home/potato/RC_2026
mkdir -p log/bags

# 示例：路线B 第1次，改动后版本
ros2 bag record \
  -o log/bags/after_routeB_run01 \
  /odometry \
  /tf \
  /tf_static \
  /cmd_vel \
  /compute_time_ms \
  /collision_check_outside_map_count \
  /collision_check_ms \
  /collision_d_min \
  /v_safe \
  /DM_IMU
```

停止录制：`Ctrl + C`。  
建议命名规则：`{before|after}_route{A|B|C}_run{01..}`。

### 1.4 开录前一键开启调试发布（建议）

```bash
ros2 param set /controller_server FollowPath.publish_debug true
ros2 param get /controller_server FollowPath.publish_debug
```

### 1.5 A/B/C 可直接复制的录制命令（run01 示例）

```bash
cd /home/potato/RC_2026
mkdir -p log/bags

# Route A - 基线(before)
ros2 bag record -o log/bags/before_routeA_run01 \
  /odometry /tf /tf_static /cmd_vel /compute_time_ms /collision_check_outside_map_count \
  /collision_check_ms /collision_d_min /v_safe /DM_IMU

# Route A - 改动后(after)
ros2 bag record -o log/bags/after_routeA_run01 \
  /odometry /tf /tf_static /cmd_vel /compute_time_ms /collision_check_outside_map_count \
  /collision_check_ms /collision_d_min /v_safe /DM_IMU

# Route B - 基线(before)
ros2 bag record -o log/bags/before_routeB_run01 \
  /odometry /tf /tf_static /cmd_vel /compute_time_ms /collision_check_outside_map_count \
  /collision_check_ms /collision_d_min /v_safe /DM_IMU

# Route B - 改动后(after)
ros2 bag record -o log/bags/after_routeB_run01 \
  /odometry /tf /tf_static /cmd_vel /compute_time_ms /collision_check_outside_map_count \
  /collision_check_ms /collision_d_min /v_safe /DM_IMU

# Route C - 基线(before)
ros2 bag record -o log/bags/before_routeC_run01 \
  /odometry /tf /tf_static /cmd_vel /compute_time_ms /collision_check_outside_map_count \
  /collision_check_ms /collision_d_min /v_safe /DM_IMU

# Route C - 改动后(after)
ros2 bag record -o log/bags/after_routeC_run01 \
  /odometry /tf /tf_static /cmd_vel /compute_time_ms /collision_check_outside_map_count \
  /collision_check_ms /collision_d_min /v_safe /DM_IMU
```

- `run02` / `run03`：将命令中的 `run01` 改成 `run02`、`run03` 即可。
- 每次录制结束后用 `Ctrl + C` 停止，确认目录下已生成对应 bag。

### 1.6 一键录包脚本（推荐）

脚本路径：`tools/record_controller_bag.sh`

```bash
cd /home/potato/RC_2026

# Route B, after, run01
tools/record_controller_bag.sh --route B --phase after --run 01

# Route C, before, run02，120秒自动停止
tools/record_controller_bag.sh --route C --phase before --run 02 --duration 120

# 录制前自动开启 publish_debug
tools/record_controller_bag.sh --route A --phase after --run 03 --enable-debug
```

仅查看将执行的命令（不真正启动录制）：

```bash
tools/record_controller_bag.sh --route B --phase after --run 01 --dry-run
```

## 2. 怎么获取当前参数

### 2.1 获取运行时参数（controller_server）

先确认节点在线：

```bash
ros2 node list | rg controller_server
```

列出 FollowPath 参数：

```bash
ros2 param list /controller_server | rg '^FollowPath\.'
```

读取单个参数：

```bash
ros2 param get /controller_server FollowPath.lateral_error_gain
ros2 param get /controller_server FollowPath.brake_margin
ros2 param get /controller_server FollowPath.enable_curvature_ff
```

导出运行时参数快照（建议每轮调参后保存）：

```bash
mkdir -p log/params
ros2 param dump /controller_server > log/params/controller_server_$(date +%F_%H%M%S).yaml
```

### 2.2 获取配置文件参数（持久化参数）

```bash
rg -n "FollowPath:|brake_margin|brake_accel|lateral_error_gain|lateral_error_max|enable_curvature_ff|a_lim_x|a_lim_y" \
  src/rc26_bringup/config/nav2_params.yaml
```

## 3. 怎么修改参数

### 3.1 运行时临时修改（立即生效，重启后失效）

> 下列参数已支持动态更新：`brake_margin`、`brake_accel`、`lateral_error_gain`、`lateral_error_max`、`enable_curvature_ff`、`a_lim_x`、`a_lim_y`、`publish_debug`。

```bash
ros2 param set /controller_server FollowPath.lateral_error_gain 1.7
ros2 param set /controller_server FollowPath.a_lim_x 1.2
ros2 param set /controller_server FollowPath.a_lim_y 0.7
ros2 param set /controller_server FollowPath.enable_curvature_ff false
ros2 param set /controller_server FollowPath.publish_debug true
```

修改后立即复核：

```bash
ros2 param get /controller_server FollowPath.lateral_error_gain
ros2 param get /controller_server FollowPath.a_lim_x
```

### 3.2 持久化修改（重启后仍生效）

1. 编辑 `src/rc26_bringup/config/nav2_params.yaml` 中 `FollowPath` 段参数。  
2. 重新构建并 source：

```bash
cd /home/potato/RC_2026
colcon build --parallel-workers 1 --packages-select rc26_bringup rc26_omni_controller
source /home/potato/RC_2026/install/setup.bash
```

3. 重启 bringup 后再次用 `ros2 param get` 核对。

## 4. 调参与验收建议流程

1. 启动系统，确认 `controller_server` 在线。  
2. 按路线 A/B/C 录制 `before` 对照包。  
3. 每次只改 1~2 个参数，先用 `ros2 param set` 做临时试验。  
4. 每轮试验录制 `after` 包，并 `ros2 param dump` 保存参数快照。  
5. 参数收敛后回填 `nav2_params.yaml`，重建并复测。

## 5. 常用检查命令

```bash
# 关键调试 topic 是否存在
ros2 topic list | rg "compute_time_ms|collision_check_ms|collision_d_min|v_safe"

# 观察碰撞检测耗时
ros2 topic echo /collision_check_ms

# 观察连续制动相关量
ros2 topic echo /collision_d_min
ros2 topic echo /v_safe
```

## 6. 常见问题

- `ros2 param set` 失败：先确认 `/controller_server` 已激活。  
- 修改 YAML 后未生效：确认已重新 `colcon build` 且重新 `source install/setup.bash`。  
- 频繁出现 `KeepoutFilter: Filter mask was not received`：这是地图过滤器链路问题，和控制器参数本身无直接冲突，需单独排查 keepout mask 输入。
