# Small GICP 模块说明

## 模块简介
`small_gicp` 是一个高效、轻量的点云配准基础算法库，为机器人提供底层的点云匹配能力。本项目在此基础上进行了深度定制，以适应 R2 机器人的边缘计算平台（Qualcomm QCS8550）和复杂的比赛环境。

## 核心功能
1. **多线程并发加速**：充分利用多核 CPU 资源，实现高实时性的点云配准。
2. **高鲁棒性代价函数**：集成了 Huber 等鲁棒核函数（Robust Kernel），有效抑制动态障碍物和噪点对配准精度的干扰。
3. **自适应优化策略**：支持 Gauss-Newton (GN) 和 Levenberg-Marquardt (LM) 优化算法的动态切换，在保证精度的同时大幅度降低计算开销。
4. **协方差与退化评估**：在配准完成后，能够基于 Hessian 矩阵计算位姿的不确定性（协方差），为上层的传感器融合提供可靠的数学依据。
