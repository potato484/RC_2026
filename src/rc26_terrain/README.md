# rc26_terrain

rc26_terrain 模块是专为 RC_2026 机器人设计的地形感知与语义分割模块。它能够将雷达（如 Mid-360）获取的三维点云数据实时处理，并根据设定的地形特征（如坡度、粗糙度、高度方差）将环境抽象化为含有语义信息的地形栅格地图。

## 主要功能

- **动态地形高度估计 (Dynamic Ground Height Estimation):** 通过对每个局部网格内的点云进行分位数估计与指数移动平均（EMA），该模块能够适应不同的地形起伏，动态估算每个单元格的地面参考高度。
- **地形特征提取 (Terrain Features Extraction):** 计算局部的地表属性，包括坡度、表面粗糙度（基于高度方差的代理计算）、局部点云密度等关键指标，反映出真实世界路况的复杂性。
- **障碍物检测 (Obstacle Detection):** 基于网格内点云的最大高度（与地面参考高度差值），识别出正向障碍物（如台阶、墙壁），并生成对应的代价栅格地图（`/terrain_obstacles`）。
- **悬崖与坑洼检测 (Drop/Negative Obstacle Detection):** 利用点云稀疏区域及深度信息，结合连通域分析（BFS去噪）过滤孤立噪点，准确识别负向障碍物（如悬崖、深坑），输出相应的代价栅格地图（`/terrain_drop`）。
- **自适应速度约束生成 (Adaptive Speed Limit Generation):** 综合当前视角内的最大坡度、最大粗糙度和最高悬崖风险，计算出安全行驶的安全建议速度限制（TCI模型），并通过 `/terrain_speed_limit` 话题高频下发给底盘控制或位姿融合节点，保障导航安全。
- **侧倾补偿与传感器融合 (Roll Compensation):** 支持接入机器人的当前位姿（如 Roll 角），对点云的投影高度进行动态补偿，在侧坡等复杂场景下显著降低高度估计的误差。

## 数据流向

- **输入:** 
  - 来自 LiDAR 的实时点云数据（默认话题如 `/mid360/points`）。
  - 基于 TF 树的传感器到基座的坐标变换（如 `base_link` -> `mid360`）。

- **输出:**
  - `OccupancyGrid` 类型的正向障碍物地图。
  - `OccupancyGrid` 类型的负向障碍物（悬崖/坑）地图。
  - `Float32` 类型的实时地形限速建议。
  - （可选）包含丰富语义信息的地形特征总线消息，为更高阶的学习型模块或路径规划模块提供基础数据支持。

## 系统集成

该模块作为 `rc26` 导航栈的重要前置感知组件，与上层的代价地图系统（如 Nav2 Costmap 2D）无缝集成。它不仅可以为全局和局部路径规划提供明确的可通行区域边界，其输出的限速建议也能直接作用于底层运动控制节点，构建快速响应的硬件级安全闭环。
