# RC26 LIO State Predictor

## 模块简介
本模块主要用于解决里程计估计与底层控制之间的时间同步与延迟补偿问题。由于激光里程计（LIO）的计算存在一定耗时，其输出的状态通常滞后于当前系统时刻。为了保证控制器能够基于最新的状态进行闭环控制，本模块利用高频 IMU 数据和运动学模型，将里程计状态前向预测至当前时刻（或指定的未来时刻），并以较高频率发布预测后的控制状态。

## 核心功能
1.  **状态预测**：基于最近一帧里程计状态，利用 IMU 角速度积分推算姿态，利用常速度模型推算位置，实现从测量时刻到当前时刻的精准对齐。
2.  **高频输出**：独立于里程计输入频率，以更高频率（默认 200Hz）发布预测状态，满足底层控制器的控制周期需求。
3.  **协方差膨胀**：根据预测时间跨度，动态增加位置和姿态的协方差，反映预测引入的不确定性。
4.  **退化状态监控**：接收上游的退化分数，根据设定阈值判断当前定位是否可靠，并输出降级标志供控制器进行安全策略切换。

## 输入输出
*   **输入**：
    *   激光里程计数据（包含位姿、速度、时间戳）。
    *   高频 IMU 数据（用于姿态积分）。
    *   环境退化评分（用于判断定位质量）。
*   **输出**：
    *   控制专用状态（对齐至当前时刻的高频里程计）。
    *   控制层退化标志（布尔值，指示是否需要降级处理）。
    *   透传的退化评分。

## 关键参数说明
模块支持配置发布频率、预测时间偏移量（用于离线调试或额外超前预测）、协方差膨胀系数（位置与航向角）以及退化判定阈值。用户可根据实际控制链路的延迟特性和传感器噪声水平进行调整。
