# rc26_sensor_scan

## 模块简介

`rc26_sensor_scan` 是 RC_2026 机器人感知系统中的高级数据处理与同步对齐模块。其主要职责是接收系统中的全局点云数据和底盘里程计数据，在时间维度上对它们进行严格匹配对齐，并在空间维度上完成逆向坐标系投影，从而为下游的局部避障、感知算法提供“干干净净”的、以传感器本体为视角的同步点云与位姿。

## 核心功能描述

### 1. 异构数据的时间同步
系统中的 3D 激光雷达产生高吞吐量的稠密点云，而底盘里程计模块则输出高频的位置信息。由于两者数据流的产生路径和处理延时不同，到达本模块的时间戳存在细微偏差。本模块内部集成了基于近似时间戳（Approximate Time）的缓冲与同步策略，自动捕获时间轴上最为匹配的点云帧和里程计帧，确保输出的每一帧点云都有一个精确对应的机器人瞬时位姿。

### 2. 逆向空间坐标系投影
上游建图算法通常为了维持全局一致性，会输出基于全局里程计坐标系的点云（即地图点云）。然而，对于机器人的局部路径规划和动态避障算法来说，往往需要以机器人自身（或传感器）当前的局部视角来看待周围环境。本模块实时查询系统的动态 TF 树，提取瞬时的坐标系映射关系，将庞大的全局点云逆向旋转、平移，准确无误地投影回传感器本体的局部坐标系中。

### 3. 数据捆绑与分发
在完成时间轴的对齐和空间轴的投影后，本模块将处理好的局部视角的点云数据与对应的机器人本体里程计数据“捆绑”在一起同步发布出去。这种同步分发机制大幅降低了下游感知和决策算法的开发复杂度，它们无需再花费计算资源去处理繁琐的时间戳对齐和空间逆变换。

### 4. 数据精简与链路去噪
在系统的迭代演进中，本模块被设计为遵循“透传与最小化处理”原则。它抛弃了冗余的二次数据运算（例如对速度的重复求导），转而直接利用上游传递的精准状态量。这不仅节省了处理器的计算算力，更从根源上消除了数据级联处理可能引发的噪声放大问题，保障了整个感知控制链路的信号纯净度。

## 在系统中的地位

`rc26_sensor_scan` 是实现“全局认知”到“局部感知”视角切换的核心枢纽。如果没有该模块，机器人的底层传感器数据和高层决策规划模块之间将存在巨大的“时空错位”。它通过高效的时空同步与变换计算，为机器人后续的精准运动控制和安全避障筑牢了数据基础。
