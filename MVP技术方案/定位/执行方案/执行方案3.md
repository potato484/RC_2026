# 改进方案3 代码实施计划（QCS8550/AidLux 综合版）

## 背景

改进方案3 针对 QCS8550 + AidLux 环境补全三项缺失能力：
1. 线程亲和：配准线程绑定 Gold 核，规避 Silver，保障 50Hz 控制闭环
2. 鲁棒性 S1/S2/S3：IMU 碰撞门控 + Hessian 退化拒绝 + SC 对称歧义拒绝
3. ARM 编译优化：使能自动向量化，降低单帧配准时延

**探索基线：**
- `result.H`（6×6 Hessian）已由 small_gicp 暴露，S2 直接可用
- S1/S2/S3 均不存在，全部从零实现
- `scripts/` 目录为空，AidLux 脚本需新建
- `CMakeLists.txt` 无 ARM 优化标志

### T3：S1 IMU Spike 门控

**目的**：碰撞瞬间冻结配准种子，同时暂停绑架计数累加。

**坐标链路边界（补充）**：
- Point-LIO（EKF）持续输出高频 `odom->base_link`。
- `rc26_localization` 负责慢速纠偏 `map->odom`。
- S1 触发窗口内仅冻结 `map->odom` 更新与绑架计数，不中断 `odom->base_link` 连续性。
- 窗口结束后恢复 `map->odom` 更新，继续按现有状态机执行。

**hpp 新增：**
```cpp
bool   s1_enable_{false};
std::string s1_imu_topic_{"/livox/imu"};
double s1_accel_threshold_{20.0};   // m/s²
double s1_gyro_threshold_{6.0};     // rad/s（双维度检测）
int    s1_freeze_duration_ms_{300};

rclcpp::Subscription<sensor_msgs::msg::Imu>::SharedPtr imu_sub_;
std::atomic<bool>  imu_spike_active_{false};
rclcpp::Time       imu_spike_deadline_;
std::mutex         imu_spike_mutex_;
```

**imuCallback 逻辑：**
```cpp
void LocalizationNode::imuCallback(const sensor_msgs::msg::Imu::SharedPtr msg) {
    const double acc_norm = std::sqrt(
        msg->linear_acceleration.x * msg->linear_acceleration.x +
        msg->linear_acceleration.y * msg->linear_acceleration.y +
        msg->linear_acceleration.z * msg->linear_acceleration.z);
    const double gyro_norm = std::sqrt(
        msg->angular_velocity.x * msg->angular_velocity.x +
        msg->angular_velocity.y * msg->angular_velocity.y +
        msg->angular_velocity.z * msg->angular_velocity.z);

    if (acc_norm > s1_accel_threshold_ || gyro_norm > s1_gyro_threshold_) {
        std::lock_guard<std::mutex> lk(imu_spike_mutex_);
        imu_spike_deadline_ = now() + rclcpp::Duration(0, s1_freeze_duration_ms_ * 1'000'000);
        imu_spike_active_.store(true);
    }
}
```

**performRegistration() 内 S1 门控（种子更新前）：**
```cpp
if (s1_enable_ && imu_spike_active_.load()) {
    rclcpp::Time deadline;
    { std::lock_guard<std::mutex> lk(imu_spike_mutex_); deadline = imu_spike_deadline_; }
    if (now() < deadline) {
        RCLCPP_WARN_THROTTLE(get_logger(), *get_clock(), 500,
            "S1: IMU spike gate active, seed frozen");
        return;  // 跳过种子更新 & 暂停绑架计数
    }
    imu_spike_active_.store(false);
}
```

### T4：S2 Hessian 退化轴拒绝

**目的**：识别走廊/对称环境退化方向，连续触发则强制 GLOBAL_RECOVERY。

**hpp 新增：**
```cpp
bool   s2_enable_{false};
double s2_hessian_min_eigenvalue_{100.0};  // ⚠️ 需根据实测 Hessian 量纲标定
                                            // （参考值：Codex 建议 1e-4，Claude 建议 100.0；
                                            //  small_gicp 原始 H 量级通常 1e3~1e5 量级，
                                            //  建议先跑 T0 日志采样后确定）
int    s2_max_continuous_frames_{10};
std::atomic<int> consecutive_s2_count_{0};
```

**performRegistration() 内，align() 返回后，S1 门控之前：**
```cpp
if (s2_enable_ && result.converged) {
    Eigen::SelfAdjointEigenSolver<Eigen::Matrix<double, 6, 6>> solver(result.H);
    const double min_eig = solver.eigenvalues().minCoeff();
    if (min_eig < s2_hessian_min_eigenvalue_) {
        RCLCPP_WARN_THROTTLE(get_logger(), *get_clock(), 500,
            "S2: degenerate axis (min_eig=%.4f), update rejected", min_eig);
        if (++consecutive_s2_count_ >= s2_max_continuous_frames_) {
            consecutive_s2_count_ = 0;
            RCLCPP_ERROR(get_logger(), "S2: %d frames continuous degeneration, forcing GLOBAL_RECOVERY",
                s2_max_continuous_frames_);
            requestRelocalization(RelocTriggerReason::KIDNAP, accumulated_cloud_);
        }
        return;
    }
    consecutive_s2_count_ = 0;
}
```

### T6：AidLux 脚本

**setup_realtime_aidlux.sh**（`src/rc26_localization/scripts/`）：
```bash
#!/usr/bin/env bash
set -euo pipefail
NODE=${1:-rc26_localization_node}
PID=$(pgrep -f "$NODE" | head -1)
[[ -z "$PID" ]] && { echo "Node $NODE not found"; exit 1; }

# 进程级绑定 cpu 0-4
taskset -cp 0-4 "$PID"

# 线程级按 comm 分桶
for TID in /proc/"$PID"/task/*/; do
    tid=$(basename "$TID")
    comm=$(cat "$TID/comm" 2>/dev/null || true)
    if [[ "$comm" =~ gicp|omp|registration|lio ]]; then
        taskset -cp 1-4 "$tid" 2>/dev/null || true   # Gold
        chrt -f -p 60 "$tid" 2>/dev/null || true
    else
        taskset -cp 5-7 "$tid" 2>/dev/null || true   # Silver
    fi
done
echo "Done: $NODE (pid=$PID)"
```

**profile_localization_perf.sh**（`src/rc26_localization/scripts/`）：
```bash
#!/usr/bin/env bash
```

## 注意事项

- **S2 阈值标定**：`s2_hessian_min_eigenvalue` 两版本差异悬殊（100.0 vs 1e-4），需先通过 T0 PERF_METRIC 日志采样真实 Hessian 特征值分布后再确定最终值。
- **S2 阈值快速 SOP（MVP）**：采样 3 类 bag（正常/坡道/对称退化）各 10 分钟，统计 `min_eig` 的 `good_p05` 与 `deg_p95`；若 `deg_p95 < good_p05`，取阈值 `0.5*(deg_p95+good_p05)`，否则取 `0.8*good_p05`。连续 3 次回放满足“正常场景误拒绝 <1%、退化场景触发率 >80%”后冻结到 YAML。
- **realtime 权限降级**：`qcs8550_realtime_enable=true` 在 AidLux 无 `CAP_SYS_NICE` 时自动降级 `SCHED_OTHER`，不终止节点。
- **仅面向 R2**，不改动 R1 相关逻辑。
