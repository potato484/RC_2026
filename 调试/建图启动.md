# 建图启动

本文档对应 R2 的建图链路，核心模块为 `rc26_mid360_driver + rc26_point_lio + rc26_bringup`。当前推荐入口已经收口到 `test_mapping.launch.py`，不再要求现场手动拼装纯建图参数。

相关模块：
- [rc26_mid360_driver调试](./rc26_mid360_driver调试.md)
- [rc26_point_lio调试](./rc26_point_lio调试.md)
- [rc26_odom_interface调试](./rc26_odom_interface调试.md)
- [rc26_sensor_scan调试](./rc26_sensor_scan调试.md)
- [rc26_lio_state_predictor调试](./rc26_lio_state_predictor调试.md)

## 使用前提

- 当前工作目录位于仓库根目录：`RC_2026`
- 已完成编译，并存在 `install/setup.bash`
- 当前推荐入口会默认打开 RViz2；如果只通过 SSH/headless 运行，需要显式关闭 RViz2
- Mid-360 与机器人网络连通，默认雷达地址为 `192.168.1.140`
- `sysctl net.core.rmem_max` 不低于 `33554432`

## 编译

```bash
MAKEFLAGS='-j2 -l2' colcon build --executor sequential --parallel-workers 1 \
  --packages-select rc26_mid360_driver rc26_point_lio rc26_odom_interface rc26_sensor_scan rc26_lio_state_predictor rc26_bringup
source "${RC26_WS:-$HOME/RC_2026}/install/setup.bash"
```

## 常用启动方式

### 1. 纯建图最小链路，推荐

```bash
ros2 launch rc26_bringup test_mapping.launch.py
```

说明：

- 这是当前最推荐的建图入口
- 该入口固定复用 `bringup.launch.py`
- 默认等价于 `slam:=true pure_mapping_mode:=true point_lio_profile:=mapping_dense use_rviz:=true`
- 通过 `odometry.launch.py` 默认拉起 `rc26_mid360_driver_node`，无需另开 Mid-360 驱动终端
- 默认加载 `rc26_bringup/rviz/slam.rviz` 打开 RViz2，用于观察 `/registered_scan` 与 `/laser_map_full`
- 会跳过 `lio_state_predictor`、`rc26_terrain` 和 `rc26_decision`
- `mapping_dense` 会打开高密建图和 PCD 保存相关配置

### 2. 无图形界面或只想跑数据链路时

```bash
ros2 launch rc26_bringup test_mapping.launch.py use_rviz:=false
```

说明：

- 适用于 SSH/headless 环境，避免 RViz2 因没有 `DISPLAY` 退出
- Mid-360 驱动和 Point-LIO 建图链路仍按默认逻辑启动

### 3. 需要自动恢复 Mid-360 数据流时

```bash
ros2 launch rc26_bringup test_mapping.launch.py recover_mid360_stream:=true
```

说明：

- 如果雷达能 ping 通但 `/livox/lidar` 无数据，优先先试这一条
- 首次执行恢复脚本时耗时会更长

### 4. 兼容原始 bringup 参数入口

```bash
ros2 launch rc26_bringup bringup.launch.py \
  slam:=true \
  pure_mapping_mode:=true \
  point_lio_profile:=mapping_dense
```

这条兼容入口仍保持 headless；如需 RViz2，请另开终端手工启动。

### 5. 仅启动最小里程计链路

```bash
ros2 launch rc26_bringup odometry.launch.py \
  slam:=true \
  point_lio_profile:=mapping_dense \
  enable_lio_state_predictor:=false \
  point_lio_publish_odometry_without_downsample:=false
```

如果需要这条最小链路额外发布 `/terrain_grid_map`：

```bash
ros2 launch rc26_bringup odometry.launch.py \
  slam:=true \
  point_lio_profile:=mapping_dense \
  enable_lio_state_predictor:=false \
  point_lio_publish_odometry_without_downsample:=false \
  enable_terrain_grid_map:=true
```

## 外部可视化

`test_mapping.launch.py` 默认已经打开 RViz2。`bringup.launch.py` 与 `odometry.launch.py` 当前仍保持 headless；如果需要单独重启 RViz2 或替换显示配置，请手工启动外部工具只读消费现有 topic：

```bash
rviz2 -d "${RC26_WS:-$HOME/RC_2026}/src/rc26_bringup/rviz/slam.rviz"
```

如果你启用了 `enable_terrain_grid_map:=true`，也可以改用：

```bash
rviz2 -d "${RC26_WS:-$HOME/RC_2026}/src/rc26_terrain/rviz/terrain_semantic.rviz"
```

## 最小验收

```bash
ros2 topic hz /livox/lidar
ros2 topic hz /livox/imu
ros2 topic hz /state_estimation
ros2 topic hz /registered_scan
ros2 topic echo /laser_map_full --once --field header.frame_id
```

预期：

- `/livox/lidar` 稳定在 `10Hz`
- `/livox/imu` 稳定在约 `200Hz`
- `/state_estimation` 正常输出
- `/registered_scan` 和 `/laser_map_full` 都能看到建图结果

## 建图结束后的保存检查

```bash
ls ${RC26_WS:-$HOME/RC_2026}/src/rc26_point_lio/PCD/
```

预期：正常 `Ctrl+C` 退出后，目录下存在 `scans.pcd` 或 `scans_*.pcd`。
