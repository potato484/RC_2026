# 导航启动

本文档对应 R2 当前唯一有效的导航链路，核心模块为 `rc26_xhu_nav`。默认在定位和回环通过后，再进入本页启动导航联调。

相关模块：
- [rc26_xhu_nav调试](./rc26_xhu_nav调试.md)
- [rc26_localization调试](./rc26_localization调试.md)
- [rc26_base_ground调试](./rc26_base_ground调试.md)
- [rc26_terrain调试](./rc26_terrain调试.md)

## 使用前提

- 已完成编译，并存在 `install/setup.bash`
- `map -> odom` TF 正常
- `/odom` 正常输出
- 已准备好先验点云文件
- 定位、地形和 keepout 链路已稳定

## 编译

```bash
MAKEFLAGS='-j2 -l2' colcon build --executor sequential --parallel-workers 1 \
  --packages-select rc26_interfaces rc26_xhu_nav rc26_bringup
source "${RC26_WS:-$HOME/RC_2026}/install/setup.bash"
```

## 推荐启动方式

```bash
ros2 launch rc26_bringup test_navigation.launch.py \
  prior_pcd_file:=${RC26_WS:-$HOME/RC_2026}/src/rc26_point_lio/PCD/scans.pcd
```

说明：

- 该命令会带起定位、地形和 `rc26_xhu_nav` 的 `topo_nav_node`、`xhu_motion_mode_manager_node`、`xhu_motion_runtime_node`
- 默认 `use_decision:=false`
- 默认 `enable_graph_backend:=true`
- 当前 bringup 默认就是 headless，不再通过 launch 参数装配仓库内 GUI
- 如需观察，请改用工作区外部工具只读消费现有 topic

## 外部可视化

```bash
rviz2 -d "${RC26_WS:-$HOME/RC_2026}/src/rc26_bringup/rviz/navigation_default.rviz"
```

## 最小验收

```bash
ros2 topic echo /xhu_nav/motion_mode_state
ros2 topic echo /xhu_nav/tracking_state
ros2 topic echo /xhu_nav/local_planner_state
ros2 topic echo /xhu_nav/semantic_gate
ros2 topic echo /cmd_vel
```

预期：

- `/xhu_nav/motion_mode_state` 能反映当前运动模式
- `/xhu_nav/tracking_state` 会持续给出执行状态
- `/xhu_nav/local_planner_state` 会持续更新局部规划状态
- `/xhu_nav/semantic_gate` 能体现定位/地形/执行门控结果
- `/cmd_vel` 会随 corridor 执行更新

## 手动切模式

```bash
ros2 service call /set_xhu_motion_mode rc26_interfaces/srv/SetXhuMotionMode \
  "{mode: 'plane_move', timeout: 0.0, reason: 'manual_check'}"

ros2 service call /set_xhu_motion_mode rc26_interfaces/srv/SetXhuMotionMode \
  "{mode: 'mf_traverse', timeout: 10.0, reason: 'watchdog_check'}"
```
