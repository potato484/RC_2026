# 回环启动

本文档中的“回环”固定指 `rc26_localization` 的图后端闭环验证，不指控制侧闭环。

相关模块：

- [rc26_localization调试](./rc26_localization调试.md)
- [rc26_small_gicp调试](./rc26_small_gicp调试.md)
- [导航启动](./导航启动.md)

## 使用前提

- 基础定位已经稳定
- 重定位链已经可恢复
- 已准备真实先验地图，并能重复经过已访问区域

## 编译

```bash
cd "${RC26_WS:-$HOME/RC_2026}"
MAKEFLAGS='-j2 -l2' colcon build --executor sequential --parallel-workers 1 \
  --packages-select rc26_localization rc26_bringup
source "${RC26_WS:-$HOME/RC_2026}/install/setup.bash"
```

## 推荐启动方式

```bash
ros2 launch rc26_bringup test_loop_closure.launch.py \
  prior_pcd_file:=${RC26_WS:-$HOME/RC_2026}/src/rc26_point_lio/PCD/scans.pcd
```

说明：

- 该入口默认 `enable_graph_backend:=true`
- 仍复用 `odometry.launch.py + localization.launch.py`
- 默认 `competition_mode:=false`，便于现场观察闭环状态

## 最小验收

```bash
ros2 topic echo /localization/loop_closures
ros2 topic echo /localization/backend_status --once
ros2 topic echo /localization/route_observability --once
```

预期：

- `/localization/loop_closures` 能看到闭环候选或接受记录
- `/localization/backend_status` 中 `accepted_loop_count` 与 `last_loop_age_sec` 会更新
- 闭环建立后，定位状态不应明显劣化

## 失败回退

- 先回到 [重定位启动](./重定位启动.md)
- 如果基础配准本身不稳，再退回 [定位启动](./定位启动.md)
