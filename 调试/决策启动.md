本文档对应 R2 当前自动决策链路，核心模块为 `rc26_decision + rc26_kfs_keepout + rc26_xhu_nav`。

## 使用前提

- 已完成编译，并存在 `install/setup.bash`
- `map -> odom` TF 正常
- `/mechanism/state` 正常发布
- `/kfs_keepout_heartbeat` 正常发布
- topo 图文件与 `team` 配置一致

## 编译

```bash
MAKEFLAGS='-j2 -l2' colcon build --executor sequential --parallel-workers 1 \
  --packages-select rc26_decision rc26_kfs_keepout rc26_xhu_nav rc26_bringup
source "${RC26_WS:-$HOME/RC_2026}/install/setup.bash"
```

## 常用启动方式

### 1. 单独启动决策节点

```bash
ros2 launch rc26_decision decision.launch.py enable_vision:=false
```

### 2. 通过整车 bringup 启动自动链路

```bash
ros2 launch rc26_bringup bringup.launch.py \
  slam:=false \
  use_decision:=true \
  prior_pcd_file:=${RC26_WS:-$HOME/RC_2026}/src/rc26_bringup/pcd/default.pcd
```

### 3. 启动带视觉的决策

```bash
ros2 launch rc26_decision decision.launch.py enable_vision:=true
```

## 外部可视化

```bash
rviz2 -d "${RC26_WS:-$HOME/RC_2026}/src/rc26_bringup/rviz/navigation_default.rviz"
```
