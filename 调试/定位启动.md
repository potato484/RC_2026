# 定位启动

本文档对应 R2 的基础定位链路，目标是在已有先验地图下先把 `map -> odom` 跑稳，再进入重定位和回环阶段。

相关模块：

- [rc26_localization调试](./rc26_localization调试.md)
- [rc26_small_gicp调试](./rc26_small_gicp调试.md)
- [rc26_point_lio调试](./rc26_point_lio调试.md)

## 使用前提

- 已完成一轮建图，并准备好先验点云文件
- 上游 `/odom`、`/registered_scan` 正常
- `odom -> base_link` TF 正常

## 编译

```bash
cd "${RC26_WS:-$HOME/RC_2026}"
MAKEFLAGS='-j2 -l2' colcon build --executor sequential --parallel-workers 1 \
  --packages-select rc26_localization rc26_bringup
source "${RC26_WS:-$HOME/RC_2026}/install/setup.bash"
```

## 推荐启动方式

```bash
ros2 launch rc26_bringup test_localization_chain.launch.py \
  prior_pcd_file:=${RC26_WS:-$HOME/RC_2026}/src/rc26_point_lio/PCD/scans.pcd
```

说明：

- 该入口会同时带起 `odometry.launch.py + localization.launch.py`
- 默认 `competition_mode:=false`
- 默认 `enable_graph_backend:=false`，先只验证基础定位

## 最小验收

```bash
ros2 run tf2_ros tf2_echo map odom
ros2 topic echo /localization/pose_with_cov --once
ros2 topic echo /localization/diagnostics --once
ros2 topic echo /localization/health --once
```

预期：

- `map -> odom` 持续存在
- `/localization/pose_with_cov` 连续输出
- `/localization/diagnostics` 和 `/localization/health` 没有长期停在异常态

## 下一步

- 基础定位稳定后再进入 [重定位启动](./重定位启动.md)
- 不要在基础定位不稳时直接进入回环或导航
