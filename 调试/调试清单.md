# 调试清单

本页是兼容入口，当前真实联调顺序请优先查看 [联调顺序](./联调顺序.md)。

如果你要单独排查模块，请回到 [调试入口](./README.md) 选择对应模块文档。

## 导航快速检查

```bash
cd "${RC26_WS:-$HOME/RC_2026}"
MAKEFLAGS='-j2 -l2' colcon build --executor sequential --parallel-workers 1 \
  --packages-select rc26_interfaces rc26_localization rc26_decision rc26_bringup
source "${RC26_WS:-$HOME/RC_2026}/install/setup.bash"

ros2 launch rc26_bringup test_navigation.launch.py \
  prior_pcd_file:=${RC26_WS:-$HOME/RC_2026}/src/rc26_point_lio/PCD/scans.pcd \
  nav2_map_file:=${RC26_WS:-$HOME/RC_2026}/src/rc26_bringup/map/default.yaml
```

验收命令：

```bash
ros2 lifecycle get /map_server
ros2 lifecycle get /planner_server
ros2 lifecycle get /controller_server
ros2 lifecycle get /behavior_server
ros2 lifecycle get /bt_navigator
ros2 lifecycle get /velocity_smoother
ros2 action info /navigate_to_pose
ros2 topic echo /plan --once
ros2 topic echo /global_costmap/costmap --once
ros2 topic echo /local_costmap/costmap --once
ros2 topic echo /cmd_vel
```

发送目标：

```bash
ros2 action send_goal /navigate_to_pose nav2_msgs/action/NavigateToPose \
  "{pose: {header: {frame_id: 'map'}, pose: {position: {x: 1.2, y: 0.0, z: 0.0}, orientation: {z: 0.7071, w: 0.7071}}}}"
```

## 决策快速检查

```bash
MAKEFLAGS='-j2 -l2' colcon build --executor sequential --parallel-workers 1 \
  --packages-select rc26_interfaces rc26_vision rc26_decision rc26_bringup
source "${RC26_WS:-$HOME/RC_2026}/install/setup.bash"

ros2 launch rc26_bringup bringup.launch.py \
  slam:=false \
  use_decision:=true \
  prior_pcd_file:=${RC26_WS:-$HOME/RC_2026}/src/rc26_bringup/pcd/default.pcd \
  nav2_map_file:=${RC26_WS:-$HOME/RC_2026}/src/rc26_bringup/map/default.yaml
```

验收命令：

```bash
ros2 node list | grep rc26_decision
ros2 action info /navigate_to_pose
ros2 topic echo /r2/bt/debug_state --once
ros2 topic echo /r2/bt/blackboard --once
```

预期：

- Nav2 action server 在线
- `NavToPose` 节点能更新 `nav_last_exec_state`、`nav_last_distance_remaining`、`nav_last_recovery_count`
- `/cmd_vel` 只由当前启用的运动链发布
- `rc26_kfs_keepout` 已归档，决策不再等待 keepout runtime

## 常见异常

| 现象 | 建议 |
|------|------|
| action server 不存在 | 检查 `/bt_navigator` lifecycle 是否 active，确认 `nav2_bringup` 已安装 |
| costmap 空或不更新 | 检查 `/map`、`/scan`、TF 和 map_server lifecycle |
| 发送目标后无 `/cmd_vel` | 检查 action goal 是否 accepted、local costmap 是否阻塞、controller_server 日志 |
| 决策不发目标 | 检查 `/r2/bt/debug_state`、`/r2/bt/blackboard` 和 `NavToPose` 黑板键 |
| 决策 MF 阶段不推进 | 检查 `/r2/bt/debug_state`、`/r2/bt/blackboard`、视觉结果和机构状态；当前主链没有 keepout runtime |
