# 感知启动

本文档对应 R2 的感知链路，按功能拆成三部分：`sensor_scan`、`terrain`、`vision`。当前所有入口都按 headless 口径组织，图形观察请用外部工具手工订阅 topic。

相关模块：
- [rc26_mid360_driver调试](./rc26_mid360_driver调试.md)
- [rc26_sensor_scan调试](./rc26_sensor_scan调试.md)
- [rc26_terrain调试](./rc26_terrain调试.md)
- [rc26_vision调试](./rc26_vision调试.md)

## 使用前提

- 已完成编译，并存在 `install/setup.bash`
- Mid-360 点云与 IMU 正常
- `base_link -> livox_frame` 静态 TF 正常
- 若启用视觉，相机设备和模型文件路径均有效

## 1. 点云处理启动（rc26_sensor_scan）

### 编译

```bash
MAKEFLAGS='-j2 -l2' colcon build --executor sequential --parallel-workers 1 \
  --packages-select rc26_sensor_scan rc26_bringup
source "${RC26_WS:-$HOME/RC_2026}/install/setup.bash"
```

### 启动

```bash
ros2 launch rc26_bringup odometry.launch.py
```

如需在启动前自动恢复 Mid-360 数据流：

```bash
ros2 launch rc26_bringup odometry.launch.py recover_mid360_stream:=true
```

### 最小验收

```bash
ros2 topic hz /sensor_scan
ros2 topic echo /sensor_scan --once
ros2 topic echo /sensor_scan --once --field header.stamp
ros2 topic echo /odometry --once --field header.stamp
```

预期：`/sensor_scan` 频率约 `10Hz`，并且时间戳与 `/odometry` 能对齐。

## 2. 地形感知启动（rc26_terrain）

### 编译

```bash
MAKEFLAGS='-j2 -l2' colcon build --executor sequential --parallel-workers 1 \
  --packages-select rc26_interfaces rc26_terrain rc26_merge_odom
source "${RC26_WS:-$HOME/RC_2026}/install/setup.bash"
```

### 启动

```bash
ros2 launch rc26_terrain terrain_semantic.launch.py
```

### 最小验收

```bash
ros2 node info /terrain_semantic
ros2 topic hz /terrain_obstacles
ros2 topic echo /terrain_obstacles --once
ros2 topic hz /terrain_drop
ros2 topic echo /terrain_drop --once
```

### 常用在线调参

```bash
ros2 param set /terrain_semantic ground_ema_alpha 0.5
ros2 param set /terrain_semantic h_obstacle_m 0.35
ros2 param set /terrain_semantic h_drop_m 0.18
```

## 3. 视觉感知启动（rc26_vision）

### 启动独立视觉链路

```bash
ros2 launch rc26_vision vision_test_with_camera.launch.py
```

说明：默认使用 `rc26_vision` 安装目录下的 `vision_models.yaml`，当前模型链路为 AidLite + ONNX/CPU。

### 通过整车 bringup 带起视觉

```bash
ros2 launch rc26_bringup bringup.launch.py \
  slam:=false \
  use_realsense:=true \
  use_decision:=false
```

### 最小验收

```bash
ros2 topic hz /camera/color/image_raw
ros2 topic hz /vision/tip_detections
ros2 topic echo /vision/tip_detections --once
```

## 外部可视化

如果要观察点云与 terrain 调试数据，请手工启动外部 RViz：

```bash
rviz2 -d "${RC26_WS:-$HOME/RC_2026}/src/rc26_terrain/rviz/terrain_semantic.rviz"
```

若同时需要查看 Point-LIO 累计地图，可改用：

```bash
rviz2 -d "${RC26_WS:-$HOME/RC_2026}/src/rc26_bringup/rviz/slam.rviz"
```
